# Реестр штрафов ПДД для электросамокатов

## Описание проекта
Данный проект представляет собой интерактивное веб-приложение для управления списком нарушений ПДД для средств индивидуальной мобильности (СИМ). Работа объединяет в себе построение компонентного интерфейса и реализацию алгоритмической логики на чистом JavaScript.

## Основной функционал (ЛР №3)
*   **Многостраничная архитектура:** Реализован переход между главной страницей со списком и страницей детальной информации без перезагрузки (SPA-подобное поведение).
*   **Визуализация данных:** На главной странице отображаются статичные превью (PNG), а на странице детального описания — **интерактивная 3D-модель** объекта (Three.js).
*   **Адаптивная верстка:** Использование Bootstrap 5 для создания плитки карточек (строго по 2 в ряд) и навигационной панели (Navbar).
*   **Живой поиск:** Фильтрация списка нарушений в реальном времени.
